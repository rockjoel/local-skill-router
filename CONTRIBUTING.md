# Contributing

Thanks for interest.

1. Fork this repo on GitHub
2. Create a branch: `git checkout -b improve-something`
3. Make a small change + keep `python tests/test_router.py` green
4. Open a **Pull Request** against `main`

Please:

- Keep the default path **offline** (no required API key)
- Do not add secrets, personal paths, or private project names
- Prefer small PRs with a clear “why”

Issues are welcome for bugs and ideas.
